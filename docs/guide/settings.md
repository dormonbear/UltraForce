# Settings

Open settings by clicking the gear icon in the search modal.

## Search Settings

### Fuzzy Search

Enable or disable fuzzy matching. When enabled, searches like `acnt` will match `Account`.

### Search Scope

Configure which metadata types to include in searches.

## Display Settings

### Theme

UltraForce uses a dark transparent theme that adapts to your Salesforce interface.

### Result Limit

Configure the maximum number of search results displayed.

## Cache Settings

### Cache Duration

Metadata is cached for 24 hours with background refresh after 2 hours.

### Clear Cache

Manually clear the metadata cache to force a fresh fetch.

## Privacy and Local Data

UltraForce does not collect usage analytics, API request statistics, or automatic
error reports. Settings, custom commands, history, favorites, and metadata caches
stay in your browser profile to support your work. History and favorites can
include item names and descriptions; use their clear controls to remove them.

Older local error logs and API request statistics are removed automatically.
See the [privacy policy](https://github.com/dormonbear/UltraForce/blob/main/PRIVACY.md)
for storage details, Salesforce API requests, and verification limits.

## Keyboard Shortcuts

Customize the keyboard shortcut to open UltraForce in Chrome's extension settings:

1. Go to `chrome://extensions/shortcuts`
2. Find UltraForce
3. Set your preferred shortcut
