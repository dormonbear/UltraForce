# Installation

## Chrome Web Store

Install UltraForce from the Chrome Web Store:

1. Visit the [UltraForce Chrome Web Store page](https://chromewebstore.google.com/detail/ultraforce-for-salesforce/maemkmihjmlfilhpfeeindecjnagelkh)
2. Click "Add to Chrome"
3. Confirm the installation

## Permissions

| Permission | Purpose |
|------------|---------|
| `storage` | Store cached metadata and settings |
| `activeTab` | Access the current Salesforce tab |
| `tabs` | Open new tabs for navigation |
| `cookies` | Read Salesforce session for API access |
| `scripting` | Lets UltraForce restore search in open Salesforce tabs after an extension update. / 让 UltraForce 在扩展更新后恢复已打开的 Salesforce 标签页中的搜索功能。 |

## Verify Installation

1. Navigate to any Salesforce org
2. Press `Cmd+B` (Mac) or `Ctrl+B` (Windows)
3. The floating UltraForce search bar should appear / UltraForce 悬浮搜索栏应随即出现

## After an Update / 扩展更新后

UltraForce automatically reconnects to open Salesforce tabs after an extension update, so you can keep searching without reloading the page. If it shows a refresh prompt, click **Refresh** to restore search on that tab.

扩展更新后，UltraForce 会自动恢复已打开的 Salesforce 标签页中的搜索功能，无需重新加载页面。如果看到刷新提示，请点击 **刷新** 恢复该标签页的搜索功能。
